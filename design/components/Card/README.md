Rounded panel that holds page content below the header.

Use it as the container for a block of content on `surface-page`. The consumer supplies the children; the default size is 450 by 700px (`card-width`, `card-height`) and can be overridden with `width` and `height`. The 3px outline (`card-border`) and `card-shadow` are decoration, so put any text inside in `main-logo` and never rely on the outline to separate content.

- Keep corners at `radius-card`.
- Leave the card empty only as a placeholder; the source frame shows it empty.
