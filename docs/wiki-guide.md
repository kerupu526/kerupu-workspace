# 위키 문법 가이드

문서를 쓰고 고치는 사람을 위한 안내입니다. 문법은 **마크다운**을 기본으로 하고, 몇 가지만 우리 사이트 방식으로 더했습니다.

> 이 가이드는 설계 문서(`docs/wiki-syntax.md`)를 바탕으로 합니다. 기능이 완성되기 전에는 일부가 다르게 보일 수 있습니다.

---

## 1. 먼저 알아 둘 것

- **나무위키 문법과 다릅니다.** `'''굵게'''`, `[[문서]]`, `|| 표 ||`는 쓰지 않습니다. 아래 문법만 씁니다.
- **HTML 태그는 쓸 수 없습니다.** `<b>`, `<div>` 같은 태그는 글자로 그대로 보입니다.
- **문법 기호 뒤에는 공백을 둡니다.** `#제목`, `-목록`처럼 붙이면 문법으로 인식되지 않습니다. `## 제목`, `- 목록`이 맞습니다.
- **문법을 글자로 쓰려면 `\`를 앞에 붙입니다.** 예: `\*` → *, `\[` → [.

---

## 2. 빠른 참조

| 하고 싶은 것 | 이렇게 씁니다 |
|---|---|
| 큰 문단 제목 | `## 개요` |
| 작은 문단 제목 | `### 외모` |
| 목차 넣기 | `[toc]` (한 줄에 단독으로) |
| 굵게 | `**굵게**` |
| 기울임 | `*기울임*` |
| 취소선 | `~~취소선~~` |
| 글자 코드 | `` `코드` `` |
| 문서 링크 | `[글자](/dictionary/character-1)` |
| 같은 문서의 문단 링크 | `[글자](#개요)` |
| 외부 링크 | `[글자](https://example.com)` |
| 각주 | `본문^[각주 내용]` |
| 목록 | `- 항목` |
| 번호 목록 | `1. 항목` |
| 인용문 | `> 내용` |
| 수평줄 | `---` (앞뒤에 빈 줄) |
| 표 | `\| 제목 \| 제목 \|` 형식 |
| 이미지 | `![설명](업로드해서 받은 주소)` (사전의 "새 이미지 업로드"에서 올림) |
| 분류, 정보 상자 | 문서 맨 위 메타 블록 (아래 6장). 정보 상자 안에 표도 쓸 수 있음 |
| 표 칸 합치기 | 칸에 `<` (왼쪽과 합침), `^` (위와 합침) — 아래 5.4 |
| 편집용 메모 | `%%메모%%` (읽기 화면에는 안 보임) |
| 색, 정렬, 크기 | CSS 블록 (아래 7장) |
| 글 한 조각 가리기 (스포일러) | `||가릴 글||` (아래 "스포일러") |
| 긴 내용 숨기기 | 접기 블록 `+++ 제목` ... `+++` (아래 "접기") |
| 처음부터 접어 둔 문단 | `## + 문단 제목` |

## 3. 문단 (제목)

```markdown
## 개요
첫 번째 문단의 본문입니다.

### 외모
`##` 아래에 있는 작은 문단입니다.

### 성격
같은 단계의 문단입니다.

## 관계
새로운 큰 문단입니다.
```

**규칙**
- 문단 제목은 `##`부터 시작합니다. `#`은 문서 제목 자리이므로 본문에서는 쓰지 않습니다.
- 가장 깊게 쓸 수 있는 것은 `######`까지입니다. 하지만 **3단계까지만 쓰는 것을 권장**합니다. 더 깊어지면 번호가 `2.1.3.1`처럼 길어져서 읽기 어렵습니다.
- 제목 끝에 `#`을 붙이지 않습니다. `## 개요 ##`이 아니라 `## 개요`가 맞습니다.
- 번호(`1.`, `2.1.`)는 자동으로 붙습니다. 직접 쓰지 않습니다.

## 4. 텍스트, 링크, 각주

### 4.1 텍스트 서식

```markdown
**굵게**, *기울임*, ~~취소선~~
```

- 두 가지를 섞을 때는 바깥을 `**`, 안을 `*`로 씁니다: `**굵고 *기울임***`.
- 밑줄, 위첨자, 아래첨자, 글자 색, 글자 크기 문법은 **없습니다.** 색과 크기는 7장의 CSS 블록을 씁니다.

### 4.2 링크

```markdown
[캐릭터 1](/dictionary/character-1)
[2장으로 이동](#2-설정)
[공식 사이트](https://example.com)
```

- 사이트 안의 문서는 `/`로 시작하는 주소를 씁니다.
- 같은 문서 안의 문단은 `#`과 문단 제목을 씁니다. 공백은 `-`로 바꿉니다. 예: `## 관계 설명`이면 `#관계-설명`.
- 외부 링크는 `https://`로 시작해야 합니다. `javascript:` 같은 주소는 링크가 되지 않습니다.
- 링크 글자는 내용을 알 수 있게 씁니다. `[여기](...)`처럼 쓰지 말고 `[캐릭터 1 프로필](...)`처럼 씁니다.

### 4.3 각주

```markdown
이 캐릭터는 첫 등장 이후 여러 번 바뀌었다.^[원작 3권 15장 참고.]
```

- `^[` 안에 내용을 쓰고 `]`로 닫습니다. 닫는 괄호를 빠뜨리면 각주가 되지 않습니다.
- 번호는 자동으로 붙습니다. 번호를 직접 쓰지 않습니다.
- 본문의 번호를 누르거나 올리면 내용이 뜹니다. 문서 맨 아래 각주 목록에도 같은 내용이 나옵니다.
- 내용 안에 `[ ]`를 쓸 수 있습니다. 짝이 맞으면 그대로 내용입니다: `^[참고 [1]권 3장]`.
- 짝이 맞지 않는 괄호는 앞에 `\`를 붙입니다: `^[웃음 :\]]` → 웃음 :]. 역슬래시 자체는 `\\`로 씁니다.
- 내용에는 빈 줄을 넣을 수 없습니다 (줄 바꿈은 됩니다).
- **각주 안에 또 각주를 쓰지 않습니다.** 막혀 있습니다. 쓰면 그 부분은 각주가 되지 않고 글자로 보입니다.
- 각주 내용에는 링크를 쓸 수 있습니다.

## 5. 목록, 인용문, 표, 이미지

### 5.1 목록

```markdown
- 순서 없는 목록
- 두 번째 항목
  - 들여쓰기는 공백 2칸
  - 하위 항목

1. 순서 있는 목록
2. 두 번째 항목
```

- `-`, `*`, `+` 셋 중 하나를 쓰면 됩니다. **한 목록 안에서는 같은 기호를 씁니다.** 기호를 바꾸면 새 목록이 됩니다.
- 기호 뒤에는 **공백**을 둡니다.
- 번호 목록은 `1.`만 써도 자동으로 1, 2, 3이 됩니다.

### 5.2 인용문

```markdown
> 인용할 내용입니다.
>> 한 단계 더 안쪽의 인용입니다.
```

- 인용문은 **원문을 그대로 옮길 때만** 씁니다. 자기 생각을 인용문으로 쓰지 않습니다.
- 최대 3단계까지 중첩할 수 있습니다.

### 5.3 수평줄

```markdown
본문 위 문단.

---

본문 아래 문단.
```

- `---`는 앞뒤에 빈 줄이 있어야 합니다.

### 5.4 표

```markdown
| 항목 | 내용 |
|:---|---:|
| 이름 | 켈프 |
| 나이 | 25 |
```

- 두 번째 줄의 `:`로 정렬을 정합니다. `:---` 왼쪽, `---:` 오른쪽, `:---:` 가운데.
- **칸 합치기:** 칸의 내용이 `<` 뿐이면 왼쪽 칸과, `^` 뿐이면 위쪽 칸과 합쳐집니다.

  ```markdown
  | 기본 정보 | < |
  |:---|:---|
  | 이름 | 켈프 |
  | 소속 | 가 |
  | ^ | 나 |
  ```

  - 합쳐진 영역은 빈틈없는 직사각형이어야 합니다. 맨 왼쪽 칸의 `<`, 맨 윗줄의 `^`, 머리글 줄과 본문 줄에 걸치는 합치기는 안 되고, 그 칸은 `<`, `^` 글자 그대로 보입니다(편집 화면에 경고가 뜹니다).
  - 합쳐진 칸의 내용은 왼쪽 위 칸에 쓴 것이 나옵니다.
  - `<`, `^` 글자 자체를 칸에 쓰고 싶으면 `` `<` `` 처럼 코드로 씁니다.
- 표 안에 리스트나 다른 표를 넣지 않습니다.
- 열은 최대 12개, 행은 최대 300개입니다.
- 표가 화면보다 넓으면 표만 가로로 스크롤됩니다.

### 5.5 이미지

```markdown
![캐릭터 1의 얼굴 그림](업로드해서 받은 주소)
```

- 이미지 파일은 캐릭터 사전의 **"새 이미지 업로드"** 버튼(로그인 필요)으로 올립니다. 올리면 문서에 붙여 넣을 글(`![설명](주소)`과 `이미지: 주소`)이 나오고 "복사" 버튼으로 복사합니다.
- 올릴 수 있는 것은 **8MB 이하의 PNG, JPEG, WebP, GIF, SVG**입니다. SVG에 스크립트나 바깥 주소를 가리키는 내용이 있으면 올릴 수 없습니다(단순한 SVG로 다시 내보내 주세요).
- 이미지 주소는 **이 사이트에 올린 파일만** 씁니다. 다른 사이트의 그림 주소는 쓸 수 없고 편집 화면에 경고가 뜹니다.
- 설명(`[]` 안)은 **반드시** 씁니다. 화면을 읽는 프로그램이 이 글을 읽어 줍니다.
- 이미지 크기나 위치는 7장의 CSS 블록으로 정합니다.

---

## 6. 메타 블록 (분류, 정보 상자)

문서 **맨 위**에 아래처럼 씁니다. `---`로 감싸고, 본문보다 먼저 와야 합니다.

```markdown
---
분류: 등장인물, 주인공
정보:
  제목: 캐릭터 1
  작품: 작품명
  분류: 주인공
  첫 등장: 1화
  출처: 원작 1권
이미지: 업로드해서 받은 주소
---
```

- `분류`는 쉼표로 나눕니다.
- `정보` 아래 줄은 **두 칸 들여써서** 씁니다. 탭은 쓰지 않습니다.
- 정보 상자에 나오는 항목 이름은 위 예시처럼 정해진 이름을 씁니다. 이름을 임의로 바꾸면 안 나옵니다.
- `이름: 값`의 값에는 다른 문법(굵게, 링크 등)을 쓰지 않습니다. 서식이 필요하면 아래처럼 **표**를 씁니다.

**정보 상자 안에 표 쓰기**

`정보:` 아래에 `|`로 시작하는 줄을 이어서 쓰면 정보 상자 안에 표가 그려집니다. 5.4의 표와 같은 문법이고, 굵게, 링크, 스포일러(`\|\|글\|\|`)와 칸 합치기(`<`, `^`)도 됩니다.

```markdown
---
분류: 등장인물
정보:
  제목: 캐릭터 1
  작품: 작품명
  | 기본 정보 | < |
  |:---|:---|
  | 생일 | 10월 22일 |
  | 소속 | **A 팀** |
---
```

- 머리글 줄(`| 기본 정보 | < |`)은 정보 상자의 맨 위 제목처럼 **항상 가운데**에 놓입니다(열 정렬은 본문 칸에만 적용됩니다).
- 머리글 줄과 `|:---|:---|` 줄이 꼭 있어야 합니다. 없으면 표가 통째로 빠집니다.
- 표 줄 사이에 다른 줄을 끼우지 않습니다. `이름: 값` 줄은 표 위에 쓰고, 상자 안에서도 그 줄들이 위에 나옵니다.
- 표 칸 안의 `^[각주]`는 각주가 되지 않습니다.

## 7. CSS 블록 (색, 정렬, 여백)

```markdown
:::style
text-align: center;
color: #647260;
:::
이 문단은 가운데 정렬됩니다.

:::
```

- 여는 줄은 `:::style`, 닫는 줄은 `:::`입니다. 둘 다 **한 줄에 혼자** 있어야 합니다.
- 블록 안에는 `속성: 값;` 형식만 씁니다. 줄 끝의 `;`를 빼먹지 않습니다.
- 블록은 **중첩할 수 없습니다.** 블록 안에 또 `:::style`을 쓰지 않습니다.
- 블록 하나에 쓸 수 있는 속성은 최대 20개입니다.

**자주 쓰는 속성 (전체 목록은 설계 문서 3.2절)**

| 목적 | 속성 예시 |
|---|---|
| 정렬 | `text-align: left / center / right;` |
| 글자 색 | `color: #647260;` |
| 여백 | `margin-top: 16px;`, `padding: 8px;` |
| 글자 크기 | `font-size: 1.2em;` |
| 줄 간격 | `line-height: 1.8;` (1.2 ~ 2.2 사이) |
| 배치 | `display: flex;`, `gap: 12px;` |
| 커서 | `cursor: pointer;` |

**지키지 않는 것**
- `url(...)`, `expression(...)`, `@import`는 쓸 수 없습니다.
- `background-image`, `border-image`는 쓸 수 없습니다.
- `position`, `z-index`는 쓸 수 없습니다. 목록에 없는 속성은 조용히 무시됩니다.
- 테두리를 3px보다 얇게 바꾸거나 없애는 것은 권장하지 않습니다. 시각 장애가 있는 사람이 구분하기 어려워집니다.

## 스포일러 (글 한 조각 가리기)

```markdown
범인은 ||집사||였다.
```

- 가릴 글을 `||`로 양쪽에서 감쌉니다. 읽는 사람에게는 가려진 칸으로 보이고, 누르면(키보드는 Tab으로 가서 Enter) 보이고, 다시 누르면 가려집니다.
- 속에 `**굵게**`, 링크, 각주 같은 서식을 넣을 수 있습니다. 한 줄 안에서 씁니다.
- 짝이 맞지 않거나(`||`가 하나뿐) 속이 비어 있으면(`||||`) 스포일러가 되지 않고 `||` 글자가 그대로 보입니다.
- **표 안에서는** `|`가 칸 나누기라서 `\|\|가릴 글\|\|` 처럼 앞에 `\`를 붙여 씁니다. 표의 빈 칸을 `||`로 붙여 쓰면(`| a || b || c |`) 스포일러로 읽힐 수 있으니, 빈 칸은 `| a | | b |` 처럼 띄어 씁니다.
- 문단 제목과 각주 안에서는 스포일러가 되지 않습니다. `||` 글자 자체를 쓰고 싶으면 `` `||` `` 처럼 코드로 씁니다.
- 글 한 조각이 아니라 문단이나 표를 통째로 숨기려면 아래 "접기"를 씁니다.

---

## 접기 (스포일러, 긴 내용 숨기기)

```markdown
+++ 스포일러 주의
숨겨 둘 내용입니다. **서식**도, 목록도, 표도 쓸 수 있습니다.

- 항목
+++
```

- 여는 줄은 `+++ 제목`, 닫는 줄은 `+++`입니다. 둘 다 **줄 맨 앞**에서 **한 줄에 혼자** 씁니다 (인용문이나 목록 안에서는 쓸 수 없습니다).
- 읽는 사람에게는 제목 줄만 보이고, 처음에는 접혀 있습니다. 제목 줄을 누르면 펼쳐지고 다시 누르면 접힙니다.
- 제목에는 글자만 씁니다. `**굵게**` 같은 서식은 풀리지 않고 기호가 그대로 보입니다. 제목을 비우면 "더 보기"로 보입니다 (`+++` 만 쓴 줄).
- 문단이나 표를 통째로 가릴 때 씁니다. 제목에 "스포일러 주의"처럼 알려 주면 됩니다 (글 한 조각만 가릴 때는 위의 `||글||`).
- 접기 안에는 **문단 제목(`##`)을 쓸 수 없습니다.** 제목은 접기 밖에서 씁니다.
- 접기 안에 접기를 넣으려면 **바깥을 `+`를 더 많이** 씁니다 (코드 블록의 ``` 와 같은 규칙). 3단계까지 됩니다.

  ```markdown
  ++++ 바깥 접기
  바깥 내용
  +++ 안쪽 접기
  안쪽 내용
  +++
  ++++
  ```
- CSS 블록 안에 접기를, 접기 안에 CSS 블록을 넣을 수 있습니다.
- 닫는 줄을 빼먹으면 접기가 되지 않고 `+++` 글자가 그대로 보입니다.

**접어 둔 문단**: 문단 제목에 `+`와 공백을 붙이면 그 문단 전체가 처음부터 접혀 있습니다.

```markdown
## + 뒷이야기
이 문단은 제목 줄만 보이고 누르면 펼쳐집니다.
```

---

## 8. 자주 하는 실수

| 잘못 쓴 예 | 이유 | 바른 예 |
|---|---|---|
| `#개요` | `##`부터 써야 합니다 (`#`은 문서 제목) | `## 개요` |
| `*굵게*` (기대: 굵게) | `*`은 기울임입니다 | `**굵게**` |
| `-목록` | 기호 뒤에 공백이 없음 | `- 목록` |
| `[여기](/dictionary/x)` | 링크 글자가 내용을 알려 주지 않음 | `[캐릭터 X 문서](/dictionary/x)` |
| `^[각주 내용` | 닫는 `]`이 없음 | `^[각주 내용]` |
| `<b>굵게</b>` | HTML 태그는 쓸 수 없음 | `**굵게**` |
| `'''굵게'''` | 나무위키 문법 | `**굵게**` |
| 표 셀 안에서 엔터로 줄 바꿈 | 표 줄이 깨짐 | 줄 바꿈 없이 한 줄로 |
| `:::style`을 두 번 중첩 | 블록은 중첩 불가 | 블록을 나눠서 씀 |
| `+++ 접기`만 쓰고 닫는 줄이 없음 | 접기가 되지 않고 글자로 보임 | 끝에 `+++` 한 줄 |
| 접기 안에 `## 제목` | 접기 안에서는 제목을 쓸 수 없음 | 제목은 접기 밖에서 씀 |
| 제목 아래 바로 목록 없이 빈 줄 없음 | 제목과 목록이 붙어 보일 수 있음 | 제목 아래 한 줄 띄움 |

---

## 한도 (넘으면 어떻게 되나요?)

넘으면 문서가 거부되지는 않지만, 넘친 부분은 읽기 화면에서 빠지거나 바뀝니다.

| 항목 | 한도 | 넘으면 |
|---|---|---|
| 문서 길이 | 10만 자 | 뒤쪽이 잘립니다 |
| 각주 | 200개 | 넘는 각주는 `^[...]` 글자로 보입니다 |
| 이미지 | 50개 | 넘는 그림은 설명 글자만 보입니다 |
| 인용문 중첩 | 3단계 | 더 깊은 인용 표시가 없어집니다 |
| 목록 중첩 | 4단계 | 더 깊은 항목은 일반 문단이 됩니다 |
| 접기 중첩 | 3단계 | 더 깊은 접기는 펼친 채로 풀립니다 |
| 접기 제목 길이 | 100자 | 뒤가 잘립니다 |
| 표 | 열 12개, 행 300개 | 표가 통째로 빠집니다 |

## 편집 화면 쓰는 법

문서의 `편집` 버튼으로 들어갑니다. 왼쪽에 쓰면 오른쪽 미리보기가 바로 따라옵니다.

- **자동완성:** 줄 맨 앞에서 `##`, `[toc]`, `:::`, `|`, `![`, `>`, `-` 같은 기호를 치면 문법 목록이 뜹니다. 한글을 쓸 때는 뜨지 않습니다. 목록이 안 뜨면 `Ctrl` + `Space`를 누르세요.
- **CSS 블록:** `:::style` 아래 줄에서 속성 이름을 치면 쓸 수 있는 속성만 제안합니다. `:` 뒤에서는 쓸 수 있는 값을 제안합니다.
- **경고:** 문법이 어긋난 줄에 물결 밑줄이 생기고, 아래 경고 목록에서 줄 번호를 누르면 그 줄로 갑니다. 경고가 있어도 저장은 되지만 해당 부분은 읽기 화면에서 빠지거나 바뀝니다.
- **아직 없는 것:** 저장. 지금은 새로고침하면 고친 글이 사라집니다.
